# GarSpec — Spec Templates (Starter Set)

Working reference for the **Choose Spec Template** starter library. Each template is a garment type with a standard set of **points of measure (POM)** — the measurements a factory needs. These are *starting points*: users pick the closest template, then add/remove/rename points to fit their garment. The goal is a professional head-start, not an exhaustive schema.

**Review this and tell me:** which templates to keep/add/drop, and any points to add/remove per garment. Once locked, this becomes the seed data for the Spec Sheet system.

**Conventions:**
- Every POM has a **code** (POM1, POM2…) and a **name**. Codes keep the Spec Sheet and any diagram in sync.
- "HPS" = High Point Shoulder (the standard reference point for length measurements).
- Measurements are the *garment laid flat* unless noted (industry standard). Units cm (user can switch).
- **How to measure** notes are included so GarSpec can show a tooltip/hint per point — genuinely useful for students who don't know the conventions.

## TOPS

### T-Shirt / Tee
1. Chest width (1" below armhole, edge to edge)
2. Body length (HPS to hem)
3. Shoulder width (seam to seam across back)
4. Across shoulder (shoulder point to shoulder point)
5. Sleeve length (shoulder seam to cuff edge)
6. Sleeve opening / cuff width
7. Armhole (straight, seam to seam)
8. Neck width (seam to seam, inside to inside)
9. Front neck drop (HPS to neck seam)
10. Back neck drop
11. Bottom / hem width
12. Neck rib height (if ribbed)

### Long-Sleeve Tee
*(Tee points, with sleeve length extended and cuff added)*
1–11 as Tee, plus:
12. Sleeve length (CB neck to cuff, or shoulder to cuff — note which)
13. Cuff height / rib
14. Forearm width

### Polo Shirt
*(Tee base + collar/placket)*
1–11 as Tee, plus:
12. Collar height
13. Collar point length
14. Placket length
15. Placket width
16. Number of buttons (spec, not a measurement — optional note)

### Hoodie / Sweatshirt
1. Chest width
2. Body length (HPS to hem)
3. Shoulder width
4. Sleeve length (from shoulder seam)
5. Sleeve opening / cuff width
6. Armhole
7. Neck width
8. Front rise / neck drop
9. Bottom hem width (relaxed)
10. Bottom rib / hem height
11. Cuff rib height
12. **Hood height** (crown to neck seam)
13. **Hood width** (front edge to back)
14. **Pocket width** (kangaroo, if present)
15. **Pocket opening** height
16. Sleeve bicep width

### Vest / Tank
1. Chest width
2. Body length (HPS to hem)
3. Shoulder strap width
4. Across shoulder (strap to strap)
5. Armhole depth
6. Neck width
7. Front neck drop
8. Back neck drop
9. Bottom hem width
